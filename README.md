# Browser Flappy Bird — SDD

This checkout is planned for an independent implementation derived from the [feature specification](specs/001-browser-flappy-bird/spec.md). Application files (`index.html`, `style.css`, JavaScript modules, `package.json` and `tests/`) belong at the repository root. Feature documentation remains under `specs/001-browser-flappy-bird/`.

Implementation has not started. See the [plan](specs/001-browser-flappy-bird/plan.md), [planned run and validation steps](specs/001-browser-flappy-bird/quickstart.md), and [confirmed scope decisions](specs/001-browser-flappy-bird/scope-comparison.md). Vibe code and assets must not be copied or refactored into SDD. No Vibe application files are present in this checkout; moving or overwriting them is outside this plan.

Confirmed scope: current-round scores; Space/ArrowUp, mouse and desktop touch; immediate retry after loss; preserved-round resume after pause; fatal ceiling; desktop browsers; independently drawn vintage arcade art with strong colors and animations.
